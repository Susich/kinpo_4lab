Подробное описание

Класс математической модели графа дорожной сети

Хранит топологию карты в виде двумерного списка смежности и реализует алгоритмы валидации и поиска кратчайших маршрутов.

Главный метод высокоуровневого расчета оптимального маршрута

Высокоуровневая функция двухпроходного поиска маршрута.

Реализует двухпроходную стратегию: сначала ищет безопасный путь для грузовика. Если проезд заблокирован, ищет любой физический путь, чтобы выявить критические ограничения.

Аргументы
[in]startNodeНомер пункта отправления
[in]endNodeНомер пункта назначения
[in]truckГабариты транспортного средства
[out]pathСформированный итоговый список пунктов маршрута
[out]totalLenИтоговая длина рассчитанного маршрута
[out]requiredMassТребуемая масса для проезда (заполняется при RouteImpossible)
[out]requiredHeightТребуемая высота для проезда (заполняется при RouteImpossible)
Возвращает
RouteStatus Статус результата расчета (PathFound, NoRouteExists или RouteImpossible)

< Путь есть, но машина не проходит по габаритам

Низкоуровневая реализация волнового алгоритма Дейкстры

Алгоритмическая реализация поиска кратчайшего пути (Алгоритм Дейкстры).

Выполняет геометрический поиск пути. Может работать как с фильтрацией по габаритам автомобиля, так и в режиме чистого поиска (если truck == nullptr).

Двумерный ассоциативный словарь смежности графа

Ключ первого уровня — исходный узел, ключ второго уровня — смежный узел. Значение — структура Edge с физическими ограничениями дороги.
